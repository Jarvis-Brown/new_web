Overview

Brooklyn Red Handmade Pottery and Ceramic Art is a minimalist, image-forward portfolio site built for ceramic artist Brooklyn Red to showcase and manage her latest work. I was responsible for the entire project from design and frontend development to backend setup and problem-solving. The site features a responsive layout, clean aesthetic, and a custom admin-only interface for uploading, sorting, and managing gallery images.

Role

UI/UX Designer

Frontend Developer

Tools

Figma / HTML / CSS / JavaScript / Firebase / Netlify

Challenge

The artist needed a professional portfolio to showcase her ceramic work while maintaining the ability to update her gallery independently. The challenge was to create a minimalist, visually engaging website that highlighted her artwork while providing a secure and easy-to-use system for managing images without relying on a developer. The main technical challenges included:

    Firebase Integration

  • Learning how to use Firebase Storage and Firestore to upload, delete, organize, and manage gallery images.

    Drag-and-Drop Functionality

  • Implementing a gallery that allows the artist to rearrange images while saving their updated order.

    Secure Admin Access

  • Setting up Firebase Authentication so only authorized users could access the gallery management features.

    Debugging and Problem-Solving

  • Troubleshooting JavaScript and Firebase issues by researching documentation, testing solutions, and refining the functionality.

User Needs

Through conversations with the artist, I identified the key requirements for the website. She wanted a clean, professional portfolio that reflected her personal style, showcased her ceramic work, and provided a straightforward way to manage her gallery. These discussions helped guide both the visual design and the functionality of the website.

  • A clean, professional website that showcases ceramic work across devices.
  • An easy way for the artist to upload, reorder, and remove images without using a third-party Content Management System.
  • Minimalist branding and elegant typography.
  • Secure access to gallery management features through an authenticated admin interface.

Solution

I designed and developed a responsive portfolio website using HTML, CSS, JavaScript, and Firebase. The site features a custom admin interface that allows the artist to upload, delete, and rearrange gallery images without needing to modify code or rely on a developer.

By integrating Firebase Authentication, Storage, and Firestore, I created a system that securely manages artwork while keeping the visitor experience simple and visually focused. The finished website gives the artist greater control over her portfolio, allowing her to keep her gallery updated independently.

  • Firebase Authentication for secure login
  • Image upload & delete system for managing artwork
  • Drag-and-drop gallery reordering, with saved sort order in Firestore
  • Reusable UI components and clean, scalable design
  • Custom color palette and typography based on the artist’s brand tone

Designs

I worked closely with the artist to develop a visual direction that reflected her personal style while keeping her ceramic work as the main focus. The color palette combines muted lavender tones with earthy greens and warm neutrals, creating a balance between creativity and a natural, handcrafted aesthetic.

For typography, I paired Cormorant Garamond with Brittany Signature to combine elegance with a personal, handmade feel. I also used generous spacing and a minimalist layout to give each ceramic piece room to stand out without competing with unnecessary visual elements.

These design decisions helped create a cohesive experience that reflects the artist's identity while keeping the website simple and easy to navigate.

High Fidelity

Once the visual direction was approved, I moved into high-fidelity mockups that reflected the final layout, colors, and typography choices. These designs captured the full experience across desktop and mobile views, ensuring the site looked cohesive and professional on all devices. The final screens were used as a blueprint for building the live site, bringing the artist’s vision to life with precision.

Takeaways

This project strengthened my ability to approach design and development as one connected process. Working directly with the artist taught me the importance of balancing visual design with functionality, ensuring the website was both visually appealing and easy for her to manage independently.

One of my biggest learning experiences was integrating Firebase to create a custom gallery management system. Rather than relying on a traditional content management system, I used Firebase Authentication, Storage, and Firestore to build a solution tailored to the artist's needs. This gave me practical experience working with cloud services, managing dynamic content, and troubleshooting JavaScript functionality.

Moving forward, I would focus on making the admin interface even more intuitive and improving the image management workflow as the gallery continues to grow. This project reinforced the value of building websites that are not only visually engaging but also practical for the people using them.
